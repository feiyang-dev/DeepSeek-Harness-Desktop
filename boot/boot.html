关于

DeepSeek Harness 桌面版
版本 -

DeepSeek Harness 官方 Web UI 的桌面客户端，自动检测环境、安装依赖并拉起服务，开箱即用。

功能特性
  • 安装模式选择：快速启动 / 源码完整安装 / 本地修复，超时自动快速启动
  • 人性化启动引导：大百分比进度条 + 阶段提示 + 可展开命令行日志
  • 无终端窗口：所有子进程静默执行，不弹命令行窗口
  • 环境自动检测：Node.js / git / pnpm 缺失时给出对应安装引导
  • 服务自动拉起：复用已有 3080 端口服务，否则自动启动 dsh web
  • 系统托盘：关闭窗口最小化到托盘，服务保持后台运行
  • 干净退出：退出时自动清理 dsh 子进程，不留残留
  • 可打包分发：electron-builder 生成 Windows 安装程序
技术详情
  • 桌面壳：Electron 31，启用 contextIsolation 安全沙箱
  • 主进程 main.js：模式状态机 / 安装调度 / 服务拉起 / 窗口与托盘 / 进程清理
  • 预加载 preload.js：contextBridge 安全桥接渲染层与主进程 IPC
  • 启动引导页 boot/：模式选择 + 进度条 + 日志面板
  • 内嵌官方 DeepSeek Harness Web UI（http://127.0.0.1:3080）
  • 安装方式：npm 全局安装 @deepseek-ai/dsh / git clone + pnpm 构建
  • 打包：electron-builder + NSIS，生成 Windows 安装程序
